# Sort & Search: A GUI Solution

## Overview
The Sort & Search application is a Python-based graphical user interface (GUI) program that allows users to sort a list of numbers using the Bubble Sort algorithm and search for a specific number using the Binary Search algorithm. The application is built using the Tkinter library, providing a user-friendly interface for performing these operations.

## Features
- **Bubble Sort**: Sorts a list of numbers in ascending order.
- **Binary Search**: Searches for a specific number in a sorted list and returns its index.
- **User -Friendly GUI**: Simple interface for entering numbers and performing sorting and searching operations.
